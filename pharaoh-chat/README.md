# 🏛️ شات الفراعنة - Pharaoh Chat

موقع شات فوري بتصميم فرعوني مميز مع قاعدة بيانات SQLite

## ✨ المميزات

- 💬 شات فوري باستخدام WebSocket
- 🎨 تصميم فرعوني فريد (ألوان ذهبية وفيروزية)
- 💾 حفظ الرسائل في قاعدة بيانات SQLite
- 👥 نظام مستخدمين بسيط
- 📱 تصميم متجاوب (Responsive)
- 🔔 إشعارات انضمام ومغادرة المستخدمين
- 📜 عرض تاريخ الرسائل السابقة
- ⚡ أداء سريع وسلس

## 🛠️ التقنيات المستخدمة

### Backend
- **Python 3.x**
- **Flask** - إطار عمل الويب
- **Flask-SocketIO** - للاتصال الفوري
- **SQLite** - قاعدة البيانات

### Frontend
- **HTML5**
- **CSS3** - تصميم فرعوني مخصص
- **JavaScript** - التفاعل مع الشات
- **Socket.IO Client** - الاتصال الفوري

## 📦 التثبيت والتشغيل

### 1. تثبيت المتطلبات

```bash
cd pharaoh-chat
pip install -r requirements.txt
```

### 2. تشغيل الخادم

```bash
python app.py
```

### 3. فتح المتصفح

افتح المتصفح على العنوان:
```
http://localhost:5000
```

## 🎨 التصميم الفرعوني

التصميم مستوحى من الحضارة الفرعونية:
- **الألوان**: ذهبي (#daa520)، فيروزي (#20b2aa)، بني داكن
- **الخطوط**: خطوط عربية أنيقة (Amiri, Scheherazade)
- **الرموز**: رموز فرعونية (☥ عنخ، ⚱️ جرة)
- **الزخارف**: حدود وخطوط هيروغليفية

## 🗄️ قاعدة البيانات

### جدول المستخدمين (users)
- `id` - معرف فريد
- `username` - اسم المستخدم
- `joined_at` - تاريخ الانضمام
- `last_seen` - آخر ظهور

### جدول الرسائل (messages)
- `id` - معرف فريد
- `username` - اسم المرسل
- `message` - نص الرسالة
- `timestamp` - وقت الإرسال

## 🔧 الوظائف الرئيسية

### في app.py
- `handle_connect()` - معالجة الاتصال
- `handle_disconnect()` - معالجة قطع الاتصال
- `handle_join()` - انضمام مستخدم
- `handle_message()` - إرسال رسالة
- `handle_typing()` - مؤشر الكتابة

### في database.py
- `init_database()` - إنشاء الجداول
- `add_user()` - إضافة مستخدم
- `add_message()` - حفظ رسالة
- `get_recent_messages()` - جلب الرسائل
- `delete_old_messages()` - حذف الرسائل القديمة

## 🚀 الاستخدام

1. **تسجيل الدخول**: أدخل اسم المستخدم (حتى 20 حرف)
2. **إرسال رسالة**: اكتب رسالتك واضغط إرسال (حتى 500 حرف)
3. **تسجيل الخروج**: اضغط زر "خروج" في الأعلى
