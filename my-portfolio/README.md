# Pepsi Portfolio Website

موقع استعراضي لشركة Pepsi مصمم بـ HTML و CSS

## المميزات
- تصميم متجاوب (Responsive Design)
- صفحة رئيسية جذابة
- قسم عن تاريخ Pepsi
- نموذج للتواصل
- روابط وسائل التواصل الاجتماعي

## المعاينة المباشرة
يمكنك مشاهدة الموقع مباشرة عبر GitHub Pages

## التقنيات المستخدمة
- HTML5
- CSS3
- Font Awesome Icons
- Google Fonts

## ملاحظة
هذا الموقع هو عمل استعراضي ولا يمثل شركة Pepsi الرسمية
